What is this tool?

The Personal AI Playbook turns your one-off AI prompts into a reusable system, so you stop re-explaining context every time. It has four parts:

  • Workflows — saved, fill-in-the-blank prompt templates for tasks you repeat (debugging code, writing resume bullets, drafting outreach, etc).
  • Prompt Builder — assemble a one-off prompt from building blocks (role, objective, context, format...) with a live preview.
  • Loop Builder — turn any prompt into an autonomous looping prompt with a goal, evaluation criteria, and stop conditions.
  • Settings — export/import your data, switch theme, reset.

What is this?

A quick explanation of every section

Dashboard

Your home base — quick stats, quick actions, and your favorited workflows.

Workflows

Reusable prompt templates. Each one has fill-in variables, an example, and best practices. Fill it in, copy the assembled prompt, paste it into Claude or ChatGPT.

Prompt Builder

A from-scratch prompt assembler. You pick or write each building block (role, objective, context, constraints, reasoning strategy, output format, tone, examples, quality checks) and see the whole prompt build itself live.

Loop Builder

For turning a task into an autonomous "keep improving until done" prompt — useful for agentic workflows. You define the goal, how success is measured, how it should improve between attempts, when it should stop, and any safety rules.

Settings

Export/import your data as JSON, switch theme, view shortcuts, or reset everything back to defaults.
